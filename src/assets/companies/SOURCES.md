# Company logos

Local vector assets used to identify employers on the Work page. The page applies a monochrome treatment and optical sizing in CSS; the marks retain their original proportions.

- Confido: [official website](https://www.confidotech.com/), header logo from its Webflow CDN (`confido_logo_dark 1.svg`).
- Brilliant: [official website](https://brilliant.org/), header SVG wordmark. Removed website-specific classes and resolved `currentColor` for standalone display.
- Carta: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Carta-logo.svg), sourced there from Carta’s original website logo.
- Skillshare: [official brand guidelines](https://partners.skillshare.com/design), black primary logo (`SK_Primary_logo_blk.svg`).
- Wayfair: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Wayfair_2024_logo.svg), sourced there from Wayfair’s website.
